# مشکی‌مووی | MeshkiMovie

مرجع فارسی فیلم‌های سینمایی ایران در اکران، با معماری مستقل از مشکی‌مدیا (سریال ترکی) و مشکی‌دو (سریال ایرانی).

## نسخه آغازین
- صفحهٔ اصلی فارسی، واکنش‌گرا، راست‌به‌چپ و با جستجو و فیلتر ژانر
- پروندهٔ فیلم‌های دارای مدرک آغاز اکران در `data/films.json`
- تفکیک صریح «آغاز اکران» از «نمایش تأییدشدهٔ امروز»
- پیوند منبع برای هر فیلم، بدون اختراع فروش، امتیاز، سانس یا وضعیت اکران

## انتشار
ساختار فعلی یک سایت استاتیک GitHub Pages است. فایل `index.html` مستقیم منتشر می‌شود. در GitHub → Settings → Pages → Build and deployment → Source گزینهٔ **GitHub Actions** را انتخاب کنید. سپس از تب Actions گردش‌کار `Publish MeshkiMovie` را دوباره اجرا کنید. تا زمانی که Pages توسط مالک مخزن فعال نشود، اجرای `actions/configure-pages` شکست می‌خورد.

نشانی مورد انتظار **پس از موفقیت انتشار**: https://nimania.github.io/meshkimovie/\n\n### وضعیت فنی ۱۶ آبان ۱۴۰۵\nظاهر و منطق سایت روی شاخهٔ `main` موجودند، اما GitHub Pages هنوز فعال نشده است؛ اجراهای اولیه در مرحلهٔ `configure-pages` شکست خورده‌اند. تغییر `enablement: true` نیز بدون فعال‌سازی Pages نتیجه نداده است. پس نباید سایت را قبل از موفقیت workflow آنلاین معرفی کرد.\n\nصفحهٔ اصلی، طراحی واکنش‌گرا، شش پروندهٔ قابل مشاهده با آدرس `?film=<slug>`، جستجو و فیلتر ساخته شده‌اند. آمار فروش و سانس روزانه هنوز وارد سایت نشده‌اند.

## توسعه بعدی
دریافت خودکار برنامه اکران از منابع معتبر و سامانه‌های بلیت، بانک اطلاعات فیلم و عوامل، فروش هفتگی با منبع، خبر، تریلر رسمی، و صفحه مستقل هر فیلم؛ به همراه صف تأیید خبر و حذف موارد منقضی‌شده از برچسب «روی پرده».

## سیاست تحریریه
- منبع اولیه سینما/پخش‌کننده و سامانه‌های بلیت، مرجع وضعیت فعال امروز است.
- خبر آغاز اکران به معنای فعال بودن تمام سالن‌ها در تمام روزها نیست.
- همهٔ خبرها به زبان مستقل با ارجاع منتشر شوند؛ تصاویر و ویدئوها فقط با مجوز یا امکان پیوند معتبر.
- در صورت نبود داده، «نامشخص/در انتظار بررسی» نمایش داده شود.
